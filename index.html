기프트카드 구매 안내

아래 4단계로 간단하게 구매하실 수 있습니다.

어떤 상품인가요?

(상품명, 사용처, 사용 가능 지역, 유효기간 등을 적으세요.)

1카카오톡 친구추가 후 대화

  • 아래 버튼 또는 카카오톡 ID 검색으로 친구추가를 해주세요.
  • 친구추가 후 대화 메시지를 남겨주시면 안내해 드립니다.
카카오톡으로 문의하기

2구매 전 고지사항 설문 작성

안전한 거래를 위해 구매 전 설문 작성이 필요합니다. 순서대로 확인해 주세요.

  • 거래 및 환불 안내 — 기프트카드는 코드 전달 후 단순 변심에 의한 취소·환불이 제한됩니다.
  • 금융사고 예방 안내 — 본인 명의의 정당한 자금으로만 결제해야 하며, 타인 자금이나 제3자 요청에 의한 대리 송금은 허용되지 않습니다.
  • 주문번호 4자리 입력 — 대화에서 판매자가 직접 안내해 드린 번호를 입력해 주세요.
  • 최종 동의 체크 — 위 내용을 모두 확인했다면 동의란에 체크 후 제출합니다.
⚠️ 주문번호는 임의로 만들지 마시고, 판매자에게 안내받은 번호를 그대로 입력해 주세요.
설문 작성하러 가기

3카카오톡 송금

  • 채팅방 하단의 ＋ 버튼을 누릅니다.
  • 송금을 선택한 뒤 송금하기를 누릅니다.
  • 안내받은 고시환율 기준 금액을 입력해 송금합니다. (별도 수수료 없음)

4코드 수령 및 등록

  • 입금 확인 후 판매자가 16자리 기프트카드 코드를 안내해 드립니다.
  • (코드 등록 위치와 방법을 적으세요. 예: 사이트 로그인 → 구독 → 기프트카드)
